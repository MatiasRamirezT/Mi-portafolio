¿En qué competencia conviene revisar los errores primero?

Esta muestra sintética reúne 80 respuestas en cinco competencias de NeuroLearn. Cada fila representa un intento y registra si la respuesta fue correcta.

Tasa de error por competencia
CompetenciaIntentosErroresTasa
Competencias ciudadanas2150 %
Pensamiento lógico-matemático24833,3 %
Inglés comunicativo16425 %
Comprensión lectora y pensamiento crítico20420 %
Pensamiento científico18316,7 %

Revisaría matemáticas primero. Acumula 8 de los 20 errores de la muestra (8 de 24 intentos). Ciudadanas tiene la tasa más alta, 50 %, pero un solo error en dos intentos es poca evidencia para cambiar la enseñanza.

Cómo calculé la tasa · Ver SQL

Dividí las respuestas incorrectas por el total de intentos de cada competencia y multipliqué por 100. Una competencia sin intentos queda sin tasa.

WITH resumen AS (
  SELECT c.codigo, c.nombre, COUNT(r.id) AS intentos,
         SUM(CASE WHEN r.correcta = 0 THEN 1 ELSE 0 END) AS errores
  FROM competencias AS c
  LEFT JOIN respuestas AS r ON r.competencia = c.codigo
  GROUP BY c.codigo, c.nombre
)
SELECT codigo, nombre, intentos, errores,
       ROUND(100.0 * errores / NULLIF(intentos, 0), 1) AS tasa_error
FROM resumen
ORDER BY tasa_error DESC, intentos DESC, codigo;
