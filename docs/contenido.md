# Contenido del portafolio

El perfil se orienta a bases de datos, gestión y análisis de información, con interés en el desarrollo backend.

- **Perfil.** Presentación, enfoque profesional, ubicación y disponibilidad.
- **Experiencia.** NeuroLearn IA, proceso de marzo a noviembre de 2026, contribución individual enlazada al historial del equipo y capturas del producto. El caso SQL utiliza datos sintéticos y se identifica como un ejercicio independiente.
- **Habilidades.** Bases de datos y programación, herramientas, colaboración e idiomas.
- **Formación.** Estudios principales y cursos. Los certificados disponibles enlazan a sus copias públicas.
- **Contacto.** Correo directo, GitHub y formulario que abre un borrador en la aplicación de correo del visitante.

La versión base está en `index.html`. Cada elemento traducible lleva una clave `data-i18n` con su equivalente en `assets/js/i18n-en.js`. Para traducir un atributo se añade `data-i18n-attr`. El título de la pestaña es el mismo en ambos idiomas.
