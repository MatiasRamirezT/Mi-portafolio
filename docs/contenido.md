# Contenido del portafolio

## Fuente y objetivo

La primera versión se basa en la hoja de vida proporcionada por Matías Ramírez Torres.
El objetivo es presentar su perfil para oportunidades en soporte de software y mesa de ayuda.
`index.html` contiene la versión pública del texto; este documento recoge decisiones y pendientes.

## Secciones actuales

| Sección | Contenido |
| --- | --- |
| Perfil | Nombre, formación en curso, objetivo profesional y ubicación. |
| Experiencia | Cargo de cajero en Grupo Éxito, fechas, responsabilidades y habilidades transferibles. |
| Conocimientos | Bases de datos, programación, herramientas digitales, atención e idiomas. |
| Formación | Estudios universitarios en curso y bachillerato. |
| Certificaciones | Cursos mencionados en la hoja de vida. |
| Contacto | Correo, teléfono y disponibilidad para horarios rotativos. |

## Contenido que se incorporará cuando esté disponible

- Proyectos: problema, contexto, contribución personal, herramientas, decisiones, resultado comprobable y aprendizaje.
- Enlaces profesionales que el propietario quiera mostrar.
- PDF de la hoja de vida preparado para descarga pública.
- Fechas y enlaces verificables de las certificaciones, si se dispone de ellos.

No publicar secciones vacías ni presentar como experiencia laboral los conocimientos adquiridos en cursos.
No inventar proyectos, métricas, testimonios o credenciales.
